# Branding and identifiers

"Harmonia" is a working title (spec §2.2). It has **not** been cleared for trademark, domain or store availability; similarly named products exist. Do a naming review before public release.

## Where the name and identifiers live

| What | Location |
|---|---|
| App/product id (Android applicationId, iOS bundle id) | `capacitor.config.ts` (`appId: 'harmonia.companion'`), `android/app/build.gradle`, `android/wear/build.gradle`, `ios/App/App.xcodeproj` (`PRODUCT_BUNDLE_IDENTIFIER`) |
| Display name | `capacitor.config.ts` (`appName`), `android/app/src/main/res/values/strings.xml`, `android/wear/src/main/res/values/strings.xml`, `ios/App/App/Info.plist` (`CFBundleDisplayName`) |
| In-app copy | `src/app/core/i18n/messages.en.ts` (`app.name`, `app.tagline`, …) |
| Deep-link scheme | `harmonia://` — Android `custom_url_scheme` string, iOS `CFBundleURLTypes`, `src/app/core/services/deep-links.ts`, widget/complication sources |
| App Group | `group.harmonia.companion` — iOS entitlements, `HarmoniaWidgetsPlugin.swift`, `HarmoniaCore/WidgetSnapshot.swift` |
| Android Kotlin packages | `harmonia.companion`, `harmonia.companion.widgets`, `harmonia.companion.wear`, `harmonia.core` |
| Icons / splash | `scripts/generate-brand-assets.py` regenerates all rasters from one definition; vector mark in `android/.../drawable/ic_harmonia_mark.xml`, `src/app/shared/components/emblem.component.ts` |

The id `harmonia.companion` is deliberately not reverse-DNS of a domain the owner may not hold. Before release, pick a final id you control (e.g. `com.yourcompany.harmonia`) and replace it everywhere listed above (a case-sensitive search for `harmonia.companion` finds them all), then regenerate signing/provisioning.

## Icon

Two interlocking rings (ivory and soft rose on berry) — two lives joined, the shared lens between them. Flat, no text, legible at small sizes. Android provides adaptive (foreground + background), monochrome (themed icons) and legacy rasters; iOS uses a single 1024 px icon. All artwork is original and generated by the script.
